Раньше лог в каждом обработчике

value = {{ legacyValue() }}

@for (line of legacyLog(); track $index) {
{{ line }}
} @empty {
— пусто —
}

«Сброс» намеренно не пишет в лог — ручной эффект легко забыть продублировать.

Сейчас effect()

value = {{ value() }}

@for (line of log(); track $index) {
{{ line }}
} @empty {
— пусто —
}

effect() логирует любое изменение value — включая «Сброс» — без ручных вызовов.
