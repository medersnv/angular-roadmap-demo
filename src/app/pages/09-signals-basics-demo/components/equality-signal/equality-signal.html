По умолчанию Object.is (ссылка)

user = #{{ defUser().id }} {{ defUser().name }}

обновлений downstream: {{ defUpdates() }}

Новый объект с тем же id всё равно считается изменением — счётчик растёт.

equal по id своя проверка

user = #{{ idUser().id }} {{ idUser().name }}

обновлений downstream: {{ idUpdates() }}

«Тот же объект» с тем же id → set пропускается, downstream не дёргается.
