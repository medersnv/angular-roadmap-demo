Утечка subscribe без отписки

@if (leakyMounted()) { }

ticks = {{ lab.leakyTicks$ | async }}

живых забытых подписок: {{ lab.aliveLeaks$ | async }} не закрываются

Размонтируйте компонент — счётчик НЕ останавливается: interval всё ещё тикает. Каждое новое монтирование добавляет ещё одну вечную подписку (число летит быстрее). Уйдите на другую страницу и вернитесь — leaky-счётчик всё это время рос: утечка пережила навигацию.

Без утечки takeUntilDestroyed()

@if (safeMounted()) { }

ticks = {{ lab.safeTicks$ | async }}

активных подписок: {{ safeMounted() ? 1 : 0 }} закрывается

Размонтируйте (или уйдите со страницы) — takeUntilDestroyed() завершает поток, счётчик замирает. Сколько раз ни монтируй, живёт максимум одна подписка.

«Отписаться от всех» размонтирует оба компонента (safe закроется через takeUntilDestroyed) и принудительно гасит leaky-подписки по сохранённым в сервисе ссылкам — даже те, что утекли ДО навигации. После клика leaky-тики замирают, «живых забытых подписок» становится 0. Это и есть лечение утечки: сохранить ссылку и вызвать unsubscribe(). «Сброс» же только обнуляет числа — пока подписки живы, leaky-счётчик тут же поползёт обратно.
