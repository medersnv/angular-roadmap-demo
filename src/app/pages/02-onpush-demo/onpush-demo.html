Пример 1: @Input

Родитель: user.name = {{ user.name }}

  • Изменить имя — родитель и Default покажут «Алекс», OnPush останется на старом имени (ссылка @Input та же)
  • markForCheck() в OnPush — после мутации вручную помечает компонент; имя обновится без нового объекта
  • Новый объект — все трое обновятся (новая ссылка @Input)
  • Клик внутри OnPush — тоже запускает проверку этого компонента (как markForCheck через событие)

Пример 2: async pipe

Родитель шлёт Observable — ссылка на поток не меняется, меняются только значения внутри.

  • Следующее сообщение — родитель вызывает subject.next(...), @Input тот же
  • OnPush всё равно обновляется — | async помечает компонент для проверки

Пример 3: signal

  • Signal меняется внутри OnPush-компонента — шаблон обновляется без нового @Input
  • Angular отслеживает signal сам — подробнее про markForCheck() см. страницу CDR
