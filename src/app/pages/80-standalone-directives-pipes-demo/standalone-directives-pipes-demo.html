Живой пример 2: pure vs impure — внешнее состояние

Оба пайпа фильтруют одинаково. Разница в том, что impure-пайп читает BadgeState через inject() — без передачи аргументом. Смените бейдж кнопкой и посмотрите, какой пайп это увидит.

pure — только аргументы 
{{ pipeCode }}
impure — читает inject(BadgeState) 
{{ impurePipeCode }}
@for (b of badges; track b) { }

pure filterBy

    @for (f of fruits() | filterBy: term(); track f) {
  • {{ f }}
    • } @empty {
  • ничего не найдено
    • }

Аргументы (fruits, term) не изменились → transform() не вызван, бейдж не виден.

impure filterBy

    @for (f of fruits() | impureFilterBy: term(); track $index) {
  • {{ f }}
    • } @empty {
  • ничего не найдено
    • }

При каждом рендере читает inject(BadgeState).badge() → бейдж появляется сразу.

Когда нужен impure: когда пайп должен реагировать на состояние, которое не передать аргументом — глобальный стор, i18n, async-данные. Цена: transform() вызывается при каждом change detection, даже если аргументы не изменились.

Живой пример 3: Directive Composition API

hostDirectives позволяет встроить поведение директив прямо в компонент — без упоминания в шаблоне. Компонент CardButton получает appHighlight и appTooltip через hostDirectives, а снаружи их входы доступны как родные атрибуты. Наведите курсор на карточки.

Раньше — директивы в шаблоне 
{{ compositionBeforeCode }}
Сейчас — hostDirectives 
{{ compositionAfterCode }}

Входы директив, перечисленные в inputs, становятся входами самого компонента. Шаблон CardButton не содержит ни одной директивы — поведение добавлено снаружи, как слой. Это и есть композиция.

@for (c of cards; track c.label) { }

Наведите мышь: фон подсвечивается через HighlightDirective, тултип появляется через TooltipDirective — оба поведения встроены через hostDirectives, в шаблоне CardButton их нет.
