Push Observable — значение шлёт производитель

@if (!pushing()) { } @else { }
@for (v of pushed(); track $index) { {{ v }} } @empty { подпишитесь — значения начнут приходить сами }

Производитель решает, КОГДА присылать. Потребитель лишь реагирует (Push/Push).

«Развернули стрелки» в интерфейсе Iterator (Pull) — получили Observable (Push). Та же алгебра операторов (map/filter/reduce), что и для статических коллекций, теперь применима к событиям во времени.
