Живой пример: карточка из standalone-зависимостей

Эта карточка собрана без единого NgModule: страница импортирует standalone-компонент <app-star-rating> и пайп CurrencyPipe прямо в свой imports. Покликайте по звёздам — рейтинг прилетает через output().

imports: [StarRating, CurrencyPipe]

{{ price() | currency: 'RUB' : 'symbol' : '1.0-0' }}

Вердикт: {{ summary() }}

Ни одного @NgModule в цепочке: компонент-страница → standalone-ребёнок → standalone-пайп. Зависимости видны в коде, лишнее не попадёт в бандл.
