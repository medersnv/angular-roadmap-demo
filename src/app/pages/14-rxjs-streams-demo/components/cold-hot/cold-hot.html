Cold unicast — запрос на каждого подписчика

запусков источника = {{ svc.coldRuns$ | async }}

Холодный поток пересоздаётся на каждую подписку → 3 подписки = 3 «HTTP-запроса».

Hot shareReplay(1) — один запрос на всех

запусков источника = {{ svc.hotRuns$ | async }}

shareReplay кэширует результат → сколько ни подписывайся, источник запускается один раз.
